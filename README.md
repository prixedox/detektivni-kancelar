# Detektivní kancelář

Four Czech detective cases you solve from a full case file — police reports, statements,
autopsy, phone records, maps. Each case has three tasks; answers are checked in the browser,
progress is kept in `localStorage`.

Live: https://prixedox.github.io/detektivni-kancelar/

`index.html` is a build artifact. The case sources, generators and solutions live in a separate
private project so the answers are not published in plain text.
